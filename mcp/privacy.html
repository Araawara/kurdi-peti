Privacy Policy (English)

Kurdî Petî connector · Last updated: November 8, 2026

Data collection. Kurdî Petî requires no account, login or personal information. When an AI assistant calls a tool, only the text or word needed to answer that request is sent.

Usage and storage. Submitted text is used only to produce the response to that same request. The server has no database and does not store submitted text.

Third-party sharing. Data is not sold or shared. The server is hosted on Vercel, which may keep standard technical logs (such as IP address, time and request path) for a short period for security and debugging. See Vercel's privacy policy.

Retention. Kurdî Petî itself retains no text. Vercel's technical logs are deleted according to Vercel's standard retention periods.
