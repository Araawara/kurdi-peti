کوردیی پەتی

connector بۆ نووسینی کوردیی سۆرانیی پەتی

«کوردیی پەتی» ڕاژەکارێکی (server) لە جۆری MCP، کە یارمەتی Claude و یاریدەدەرە زیرەکەکانی تر دەدات کوردیی سۆرانی بە ڕێنووسی دروست و بێ وشەی بیانی بنووسن. فەرهەنگێکی وشەی پەتی و پشکنەرێکی دەقی تێدایە.

زیادکردن بۆ Claude

  1. لە Claude.ai بچۆ ناو «ڕێکخستنەکان» ← «Connectors».
  2. «Add custom connector» هەڵبژێرە.
  3. ناو: کوردیی پەتی، و ئەم بەستەرە بنووسە:
https://kurdi-peti.vercel.app/mcp

چوونەژوورەوە پێویست نییە. دوای زیادکردن لە وێب، لە بەرنامەی مۆبایل و کۆمپیوتەریشدا بەکاردێت.

گەڕان لە فەرهەنگ search_wordبۆ وشەیەکی بیانی، هاوتا کوردییە پەتییەکەی دەدۆزێتەوە.
پشکنینی دەق check_textدەقێکی کوردی دەپشکنێت و هەڵەی پیت و وشەی بیانی نیشان دەدات، لەگەڵ پێشنیاری چاککردن.
گەڕان searchگەڕانی گشتی لە فەرهەنگ و ڕێنماییەکاندا.
هێنانی وشە fetchزانیاریی تەواوی وشەیەک یان بەشێکی ڕێنمایی بە ناسنامەکەیەوە دەهێنێت.

English

Kurdî Petî (Pure Kurdish) is a remote MCP server that helps Claude and other AI assistants write Central Kurdish (Sorani) with correct Unicode orthography and without Arabic, Persian, Turkish or English loanwords. It provides a glossary of pure Kurdish words and a text checker.

Setup: Claude → Settings → Connectors → Add custom connector. Name: کوردیی پەتی, URL: https://kurdi-peti.vercel.app/mcp. No authentication is required. Once added on the web, it is also available in the Claude mobile and desktop apps.

Tools (all read-only except suggest_word, which stores a word suggestion for review):

  • get_guide – writing rules: orthography, punctuation, grammar.
  • search_word – find the pure Kurdish equivalent of a loanword.
  • check_text – check Kurdish text for wrong characters and loanwords, with suggested fixes.
  • search – general search across the glossary and guides.
  • fetch – fetch a full glossary entry or guide section by id.
  • ui_term – translate an app or website UI term (Save, Settings, Sign in) into pure Sorani.
  • suggest_word – suggest a new loanword and its pure Kurdish replacement for review.

Example prompts: "Check this Kurdish text and replace the loanwords." · "Translate this app's UI strings into pure Sorani."
